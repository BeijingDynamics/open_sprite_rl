## Hardware test order

1. Configuration-only inspection with no CAN interface opened.
2. CAN receive and IMU logging with motor power disabled.
3. Live no-transmit shadow inference; compare observations and targets offline.
4. Suspended single-joint low-gain MIT tests, including both differential ankles.
5. Supported standing with an independent e-stop operator.
6. Tethered low-speed stepping, then bounded straight/turn/stop protocols.

Every stage must preserve logs, configuration hashes, candidate hashes, timing
statistics, and the exact reason for any safety latch. Failure returns to the
previous stage; it does not justify widening a limit without new evidence.
